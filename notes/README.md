## Where this lives / sharing

- **For you (navigating):** this folder, in your editor or on GitHub — the links above work there. For nicer reading on any device with working links, mirror it to **Notion** (paste each file as a page).
- **For handing to people:** don't hand over the whole folder. Pick the one doc for that audience (e.g., [board-role-description.md](board-role-description.md) for a board prospect) and export it to **PDF**.
- **Note:** the links above only work in the digital folder — they won't carry into a flat PDF or Google Doc.
